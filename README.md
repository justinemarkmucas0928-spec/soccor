# Barangay Socorro Health Center — Interactive Mockup

This presentation build is designed to work **offline when opened as `index.html`**.

## Visual fixes in this build
- Replaced the previously blank remote background images with local, offline-safe medical illustrations in `assets/`.
- Added distinct medical visuals for the login, patient, nurse, doctor, and IT-admin views.
- Kept the existing motion system: subtle floating imagery, sheen effects, card hover motion, button sheen, and live-status animation.
- Rebalanced the desktop login split so the hero and sign-in side have a consistent visual height.
- Reduced the feature-card height and spacing so the content below the sign-in form stays proportional instead of becoming a long, uneven stack.
- Added missing `photo-3`, `photo-4`, and `photo-5` image definitions used by the clinical/admin views.
- Preserved responsive behavior and reduced-motion accessibility support.

## Run
Open `index.html` directly in Chrome/Edge, or serve the folder with any simple local web server.
